## 3. 시스템 설명

대학생은 여러 과목의 과제, 시험 일정, 미팅 일정과 함께 개인 일정까지 동시에 관리해야 한다.
그러나 기존의 일반적인 일정 관리 애플리케이션은 학업 중심의 일정과 과제 관리를 체계적으로 지원하지 못하는 경우가 많다.

본 프로젝트는 대학생이 학업 일정과 개인 일정을 한 곳에서 통합적으로 관리할 수 있는 시스템을 개발하는 것을 목표로 한다.

사용자는 과목별 과제와 일정을 등록하고 마감일, 우선순위, 진행 상태 등을 관리할 수 있으며,
이를 통해 보다 체계적인 학습 계획 수립이 가능하다.

또한 캘린더 기반의 일정 조회 기능을 지원하여 효율적인 시간 관리와 학습 계획 수립을 지원받을 수 있다.

## 4. 핵심 기능

### 4.1 과목별 일정 분류 등록 및 관리 기능
- 사용자는 과목별 과제, 시험, 미팅 등의 일정 등록
- 마감일, 중요도, 상세 내용 입력
- 일정 수정 / 삭제 / 조회 기능
- 과목별로 구분하여 관리

### 4.2 개인 일정 관리 기능
- 개인 일정 등록 및 관리

### 4.3 진행 상태 관리
- 예정 / 진행 중 / 완료 상태 설정
- 현재 작업 진행 상황 확인

### 4.4 캘린더 기반 일정 조회 기능
- 일정 및 과제를 캘린터 형태로 제공
- 날짜별 작업 한눈에 확인
