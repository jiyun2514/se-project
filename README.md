# se-project

Software Engineering course project - Campus Task Planner

## Project Overview

Campus Task Planner is a software engineering course project for managing academic tasks and schedules.

The system aims to help university students manage assignments, exams, meetings, and personal schedules in one place.

## Main Features

- Course-based task and schedule management
- Personal schedule management
- Task progress status management
- Calendar-based schedule view
- User authentication and data storage
